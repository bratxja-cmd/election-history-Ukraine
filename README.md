# Вибори в Україні — інтерактивна хронологія

Вертикальний таймлайн виборчих кампаній із зигзаг-розкладкою, фото подій
та фоновими «епохами президентств», що змінюються під час скролу.
Чистий HTML/CSS/JS, без залежностей. Хоститься на GitHub Pages,
вбудовується на сайти медіа через `<iframe>`.

## Файли
- `index.html` — сторінка таймлайну (верстка + логіка)
- `data.json` — дані: масив `events` (події) + масив `eras` (президентства)
- `embed-snippet.html` — код вставки на сайт медіа (з авто-висотою)

## Деплой на GitHub Pages
1. Залити файли в корінь репозиторію (гілка `main`).
2. Settings → Pages → Source: Deploy from a branch → `main` / `/root`.
3. Сторінка буде за `https://USER.github.io/REPO/`.

## data.json → events (події)
| поле | обов'язкове | опис |
|------|-------------|------|
| id | так | унікальний ідентифікатор |
| date | так | `YYYY-MM-DD` (сортування + прив'язка до епохи) |
| year | так | рік біля осі |
| type | так | `presidential` / `parliamentary` / `local` / `referendum` |
| title | так | назва |
| summary | ні | короткий опис |
| result | ні | результат |
| turnout | ні | явка (текст) |
| image | ні | URL фото події (в картці) |
| image_alt | ні | альт-текст |
| source_url | ні | посилання на джерело |

## data.json → eras (президентства, фон)
| поле | опис |
|------|------|
| id | ідентифікатор епохи |
| president | ім'я (показується у плашці) |
| years | напис років (напр. `2014–2019`) |
| start / end | межі періоду `YYYY-MM-DD` (визначають, до якої епохи належить подія) |
| tint | легкий колір фону епохи (hex) |
| portrait | URL напівпрозорого портрета (фон справа). Лишіть `""` — буде лише колір |
| portrait_alt | альт-текст портрета |

Фон працює так: під час скролу IntersectionObserver визначає, яка подія
в центрі екрана, бере її епоху за датою і плавно змінює колір фону +
портрет президента (opacity ~16%, з маскою-градієнтом праворуч), а також
плашку з ім'ям і роками. Текст карток портрет не перекриває.
